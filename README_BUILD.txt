Bali Control Android project

Что это:
- Android-приложение-обёртка для Bali Control v2.
- Карта и интерфейс лежат локально в assets.
- Интернет нужен для карт и внешних источников данных.
- Геолокация разрешена на Android.

Сборка:
- JDK 17+
- Android SDK 35
- Gradle / Android Studio
Команда:
  ./gradlew assembleDebug

APK появится:
  app/build/outputs/apk/debug/app-debug.apk
